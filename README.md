# model-taxonomy

A Python library for comparing collections of language models through geometric similarity — measuring how models relate to each other at the behavioral, functional, log-probability, structural, and dataset levels.

See [docs/index.md](docs/index.md) for the full documentation and [docs/CHANGELOG.md](docs/CHANGELOG.md) for the change history.
